# AI Usage Note – Fulfillment Hub

## AI Tools Used

I used ChatGPT and GitHub Copilot for brainstorming, development guidance, and debugging during the development of Fulfillment Hub.

- **GitHub Copilot:** Suggested using React, Node.js, and SQLite to build the application.
- **ChatGPT:** Recommended Streamlit and Pandas as an alternative technology stack.

## Suggestions I Evaluated

GitHub Copilot suggested React, Node.js, and SQLite. However, I chose Streamlit and Pandas because they allowed me to build and test the application faster using Python, with less setup and simpler integration of the user interface and data processing.

I also reviewed AI suggestions during development and made changes based on the project's requirements. I used my own judgment to decide which suggestions were suitable for the application.

The final technology choices and implementation decisions were made based on the project's scope, timeline, and usability requirements.
